# Dự Án Ứng Dụng HPC Students

Ứng dụng này được phát triển để giúp sinh viên tra cứu thông tin và các tiện ích liên quan một cách dễ dàng và nhanh chóng.

## Mục Lục

- [Giới Thiệu](#giới-thiệu)
- [Cài Đặt](#cài-đặt)
- [Sử Dụng](#sử-dụng)
- [Giấy Phép](#giấy-phép)

## Giới Thiệu

Ứng dụng cho phép sinh viên:
- Tra cứu học phí
- Xem lịch học
- Kiểm tra điểm rèn luyện
- ...

## Cài Đặt

Hướng dẫn cài đặt dự án trên máy tính của bạn:

1. Clone repository:
   ```bash
   git clone https://github.com/username/repo.git](https://github.com/copecute/HPC-Students.git
   ```
2. Di chuyển vào thư mục dự án:
   ```bash
   cd repo
   ```
3. Cài đặt các phụ thuộc:
   ```bash
   flutter pub get
   ```

## Sử Dụng

Để chạy ứng dụng, sử dụng lệnh sau:
```bash
flutter run
```

### Các Màn Hình Chính

- **Màn Hình Đăng Nhập**: Nhập mã sinh viên và mật khẩu để đăng nhập.
- **Màn Hình Trang Chủ**: Hiển thị các tùy chọn để tra cứu học phí, lịch học và điểm rèn luyện.
- **Màn Hình Tra Cứu Học Phí**: Hiển thị thông tin học phí của sinh viên.
- **Màn Hình Tra Cứu Lịch Học**: Hiển thị lịch học theo tuần.
- **Màn Hình Tra Cứu Điểm Rèn Luyện**: Hiển thị điểm rèn luyện của sinh viên.
- ...
